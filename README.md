## 🌟 Overview (সংক্ষিপ্ত পরিচিতি)

**Desktop Digital Clock** হলো উইন্ডোজ ডেস্কটপের জন্য তৈরি একটি আকর্ষণীয়, লাইটওয়েট এবং আধুনিক ডিজিটাল ঘড়ি উইজেট। এটি কোনো সাধারণ উইন্ডো বর্ডার ছাড়াই ডেস্কটপ স্ক্রিনের ওপর ভেসে থাকে। আপনার স্ক্রিনের সুবিধামতো যেকোনো সাইজে রিসাইজ করা যায় এবং যেকোনো স্থানে টেনে ড্র্যাগ করে রাখা যায়।

## ✨ Features (মূল ফিচারসমূহ)

- 🪟 **Frameless & Transparent**: কোনো উইন্ডো বর্ডার বা বার ছাড়া সম্পূর্ণ স্বচ্ছ ব্যাকগ্রাউন্ডে ভেসে থাকে।
- 🔄 **Smart Hover-to-Resize (স্মার্ট রিসাইজ হ্যান্ডেল)**:
  - মাউস কার্সর ঘড়ির ওপরে নিলেই নিচে ডান কোণায় হালকাভাবে রিসাইজ হ্যান্ডেল (`⤡`) ফুটে ওঠে।
  - মাউস চেপে ধরে ড্র্যাগ করে ইচ্ছামতো বড় বা ছোট করা যায়। মাউস সরিয়ে নিলে হ্যান্ডেলটি স্বয়ংক্রিয়ভাবে অদৃশ্য হয়ে যায় যাতে কোনো লেখা না ঢাকে।
- 📅 **Compact Date Format (ক্লিন তারিখ)**:
  - ডিফল্টভাবে `Thu, 19 Nov 2026` কম্প্যাক্ট ফরম্যাট থাকে, যা ঘড়িকে যত ছোটই করা হোক না কেন কখনো কেটে যায় না।
  - রাইট-ক্লিক মেনু থেকে ফুল ফরম্যাট (`Thursday, 19 November 2026`) এবং শর্ট ফরম্যাটের মধ্যে এক ক্লিকে টগল করা যায়।
- 🎨 **Adaptive Background Styles (সাদা ও কালো স্ক্রিন অ্যাডাপ্টেশন)**:
  - **Pure Transparent (Dark Screen)**: কালো বা ডার্ক ওয়ালপেপারের জন্য খাঁটি স্বচ্ছ লুক।
  - **Pure Transparent (White / Light Screen)**: সাদা স্ক্রিন বা ব্রাউজারের ওপর রাখার জন্য সাদা ব্যাকগ্রাউন্ড ব্লেন্ডিং (অক্ষরে কোনো কালো বর্ডার পড়ে না)।
  - **Sleek Widget Card**: একটি আধুনিক ডার্ক গ্লাস কার্ড ব্যাকগ্রাউন্ড, যা যেকোনো সাদা বা রঙিন ব্যাকগ্রাউন্ডে ১০০% শার্প টেক্সট দেখায়।
- 💾 **Auto-Save Settings**: ঘড়ির সাইজ, ডিসপ্লে পজিশন, রঙ, ব্যাকগ্রাউন্ড মোড এবং ১২/২৪ ঘণ্টার ফরম্যাট স্বয়ংক্রিয়ভাবে সেভ থাকে। পরের বার ওপেন করলে ঠিক আগের অবস্থাতেই চালু হবে।
- ⏱️ **12h / 24h Toggle**: ১২ ঘণ্টা (AM/PM) বা ২৪ ঘণ্টার আন্তর্জাতিক ফরম্যাটে পরিবর্তনের সুবিধা।
- 📌 **Always on Top**: অন্যান্য যেকোনো অ্যাপ্লিকেশন উইন্ডোর ওপর সবসময় দৃশ্যমান রাখার অপশন।
- 🎨 **Custom Color Picker**: রাইট-ক্লিক করে যেকোনো পছন্দের নিয়ন বা পছন্দসই কালার সিলেক্ট করার সুযোগ।
- 🔕 **100% Silent Installer**: ইনস্টলেশনের সময় কোনো প্রকার কালো CMD উইন্ডো ফ্ল্যাশ করে না।

## ⌨️ Controls & Shortcuts (নিয়ন্ত্রণ ও শর্টকাট)

| অ্যাকশন | কীভাবে করবেন? |
| :--- | :--- |
| **স্থান পরিবর্তন (Move)** | ঘড়ির ওপর মাউসের বাম বাটন চেপে ধরে স্ক্রিনের যেকোনো স্থানে ড্র্যাগ করুন। |
| **সাইজ বড়/ছোট করা (Resize)** | ঘড়ির ওপর মাউস আনলে কোণায় `⤡` আসবে, সেটি চেপে ধরে ড্র্যাগ করুন। অথবা `Ctrl +` ও `Ctrl -` চাপুন। |
| **ডিফল্ট সাইজ (Reset Size)** | `Ctrl + 0` চাপুন অথবা রাইট-ক্লিক মেনু থেকে নির্বাচন করুন। |

| **ঘড়ি বন্ধ করা (Exit)** | রাইট-ক্লিক করে **Exit Clock** সিলেক্ট করুন। |

## 💡 Portable বনাম Installer এর পার্থক্য

- **Installer (`Setup...exe`) কেন ব্যবহার করবেন?**
  আপনি যদি চান ঘড়িটি স্থায়ীভাবে ইনস্টল থাকুক, ডেস্কটপে আইকন থাকুক এবং কম্পিউটার চালু হওয়ার সাথে সাথেই ঘড়িটি স্বয়ংক্রিয়ভাবে ওপেন হয়ে যাক—তবে ইনস্টলারটি বেস্ট।
- **Portable (`Desktop...exe`) কীভাবে সবসময় চালাবেন?**
  পোর্টেবল ফাইলটিকে কম্পিউটার অন হওয়ার সাথে সাথে সবসময় চালাতে চাইলে:
  1. `DesktopDigitalClock_AsR.exe` ফাইলের ওপর রাইট-ক্লিক করে **Create shortcut** করুন।
  2. কীবোর্ডে `Windows Key + R` চাপুন, বক্সে লিখুন: `shell:startup` এবং Enter চাপুন।
  3. তৈরি করা শর্টকাট ফাইলটি ওই ফোল্ডারে পেস্ট করে দিন। এখন থেকে কম্পিউটার চালু হলেই পোর্টেবল ঘড়িটিও নিজে নিজে ওপেন হবে।

## 🛠️ Run from Source (ডেভেলপারদের জন্য)

সোর্স কোড থেকে চালাতে চাইলে আপনার কম্পিউটারে Python 3.10+ থাকতে হবে:

```bash
# Clone the repository
git clone https://github.com/<your-username>/DesktopDigitalClock.git

# Enter project directory
cd DesktopDigitalClock

# Run the clock directly
python desktop_clock.py
```

### Build Executables (EXE ফাইল তৈরি করতে)
```bash
# Build Portable Clock
pyinstaller --clean --onefile --noconsole --icon clock.ico --add-data "clock.ico;." --name DesktopDigitalClock_AsR desktop_clock.py

# Build Setup Wizard
pyinstaller --clean --onefile --noconsole --icon clock.ico --add-data "DesktopDigitalClock_AsR.exe;." --add-data "clock.ico;." --name Setup_DesktopDigitalClock_AsR installer.py
```
